Mathematical Theory ▼

The Karpelevič Region (𝒦n) is the set of all eigenvalues of n × n stochastic matrices (or nonnegative matrices with Perron eigenvalue 1).

Boundary Structure: The boundary intersects the unit circle {|z|=1} at roots of unity e2πi·p/q where p/q are Farey fractions of order n (with 0 ≤ p ≤ q ≤ n and gcd(p,q)=1).

Ito Polynomial Arcs: Adjacent Farey fractions with smaller denominator q and larger denominator s are connected by boundary arcs satisfying Ito’s reduced polynomial equation (with k = ⌊n/q⌋ and α ∈ [0, 1]):

(tq − (1−α))k = αk tqk−s  (or ts−qk(tq − (1−α))k = αk when s ≥ qk).

The Power Property: If A is an n × n stochastic matrix with eigenvalue λ, then Aᵏ is also an n × n stochastic matrix with eigenvalue λᵏ. Consequently, whenever λ ∈ 𝒦n, all powers λᵏ ∈ 𝒦n for all integers k ≥ 1.
